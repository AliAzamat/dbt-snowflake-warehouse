# dbt & Snowflake Cloud Data Warehousing

An intermediate project that turns hand-written SQL into a real analytics-engineering workflow. You build dbt models on Snowflake — sources and refs that wire a dependency graph, reusable macros, schema and singular tests that guard data quality, snapshots for slowly changing dimensions, and incremental materialization that scales transformations to billions of rows. This is the production transformation layer the enterprise platform's AI and dashboards depend on.

Built step-by-step with [KhwajaLabs Build](https://khwajalabs.com).

## Stack
- dbt
- Snowflake
- SQL
- Jinja
- Data Quality
- Cloud Data Warehouse
